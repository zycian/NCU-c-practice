- **易错点清单（自己复习用）**：① 局部变量名不能与函数名同名 ② `printf` 格式符必须与实参类型严格匹配（`%d`/`%lld`），否则 x64 下是未定义行为 ③ 函数每条分支路径都要有 `return` ④ `return 1` 别写在循环体内 ⑤ `int` 乘方要防溢出（用 `i <= n / i`） ⑥ `srand()` 只能在程序开头调用一次 ⑦ **数组作函数参数时 `sizeof(arr)` 退化为指针大小 → 必须额外传 `len`** ⑧ `arr[i]` 与 `*(arr+i)` 等价（指针与下标可互换）⑨ **数组指针必须写括号**：`int (*p)[5]` 是指针数组的指针，`int *p[5]` 是指针数组 ⑩ **"不属于范围"用 `||` 不是 `&&`**（德摩根律），且 C 不支持 `a <= x <= b` 连写比较。
- **尚未学**：字符串、结构体、共用体、动态内存、文件。
- **当前实践项目**：`扫雷练习.c`（控制台扫雷，9x9 / 10 雷）——设计要点：**双棋盘**（`mine` 存雷 + `show` 存显示）+ **外圈加边框**（`ROWS = ROW+2`，让所有格子都有完整 8 邻居，免边界判断）。
